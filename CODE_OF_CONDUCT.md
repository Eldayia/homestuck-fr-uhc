# Code de conduite

Cette communauté accueille les contributions respectueuses, précises et constructives, sans distinction d'expérience, d'identité, d'origine ou de situation personnelle.

Les comportements attendus sont : discuter des idées sans attaquer les personnes, accepter la revue, citer les sources, protéger les données privées et respecter les droits des créateurs et traducteurs.

Le harcèlement, les propos discriminatoires, l'intimidation, la publication de données personnelles et le partage de contenu protégé hors du cadre autorisé ne sont pas acceptés.

Les responsables peuvent modifier ou retirer une contribution, fermer une discussion ou limiter la participation afin de protéger la communauté et le projet. Un problème doit être signalé en privé au responsable du dépôt, via les moyens de contact visibles sur son profil GitHub. Les signalements sont examinés avec discrétion et sans représailles.

Ce code s'applique aux espaces du projet ainsi qu'aux échanges publics où une personne représente le projet.
