# Modèle de demande d'autorisation

Ce document est un brouillon. Il ne doit pas être envoyé automatiquement. Le message final doit être adapté au canal et à la personne contactée.

## Message proposé

Bonjour,

Je travaille sur **Homestuck FR for The Unofficial Homestuck Collection**, un projet communautaire non officiel qui permettrait de générer un mod de traduction française pour UHC.

Le projet sépare son code du contenu traduit. Pour le moment, aucun texte ni asset de votre traduction n'est publié dans le dépôt ou dans les releases.

Nous souhaiterions savoir si vous autorisez explicitement les usages suivants :

1. copier le texte français depuis l'aventure MSPFA pour produire le mod ;
2. effectuer uniquement les adaptations techniques nécessaires au rendu UHC ;
3. redistribuer le texte adapté dans un mod UHC public et gratuit ;
4. publier ce mod sur GitHub et dans les GitHub Releases ;
5. intégrer de la même manière les futures mises à jour de la traduction.

Concernant les images traduites ou autres assets, pourriez-vous préciser séparément :

- lesquels vous avez créés ou êtes habilité à autoriser ;
- lesquels proviennent d'autres équipes ou personnes ;
- lesquels peuvent être redistribués dans le mod ;
- les crédits et conditions à respecter pour chacun.

Crédits proposés dans le mod et le dépôt :

- projet « Homestuck en Français » avec lien vers l'aventure MSPFA ;
- pseudonymes et rôles tels que vous nous les confirmerez ;
- crédits séparés des contributeurs et équipes tierces ;
- mention claire que l'intégration UHC est un projet non officiel distinct.

Si vous êtes d'accord, pourriez-vous répondre explicitement avec :

- le périmètre autorisé : texte, images ou les deux ;
- les plateformes de redistribution autorisées ;
- les adaptations permises ;
- les crédits obligatoires ;
- les éventuelles restrictions ;
- la façon de traiter les futures contributions.

Une licence publique attachée à la traduction serait également idéale, mais une autorisation écrite claire peut au minimum nous permettre de documenter précisément votre décision.

Merci pour votre travail sur la traduction et pour votre temps.

## Après réception d'une réponse

- [ ] Conserver une référence durable à la réponse.
- [ ] Confirmer l'identité publique et le rôle de la personne répondante.
- [ ] Vérifier qu'elle peut autoriser les contributions concernées.
- [ ] Séparer le périmètre texte du périmètre assets.
- [ ] Reporter exactement les crédits exigés dans `CREDITS.md` et `NOTICE`.
- [ ] Enregistrer la date et la référence dans la politique de distribution.
- [ ] Exclure tout élément non couvert.
- [ ] Faire une revue humaine avant de changer `contentDistributionAllowed`.
